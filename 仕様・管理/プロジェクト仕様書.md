## 1. 概要・目的

### 1.1 役割
Excelシート上のテーブルデータから、プロフェッショナル品質のフローチャートを自動生成するツール。ユーザーはExcel上で構造化されたデータ（ID、図形種別、接続先、テキスト等）を準備し、本ツールのGUIから「生成」ボタンを押すことで、Excel上に自動的にフローチャート図形が描画される。

### 1.2 核心的価値
- **自動化**: 手動での図形配置・接続作業を完全に自動化し、時間を大幅に短縮
- **プロフェッショナル品質**: テキスト量に応じた動的な高さ調整、適切なコネクタ配置、テーマカラー対応
- **生存能力**: 配布（exe化）を前提とした堅牢なパス解決、自己修復機能、環境依存の排除

### 1.3 ターゲット環境
- **OS**: Windows 10/11（Excel COM操作のため）
- **Pythonバージョン**: 3.14.2（`.python-version`で固定）
- **配布形式**: PyInstallerによる単一実行ファイル（exe）
- **依存ライブラリ**: customtkinter, pywin32, python-dotenv, pyinstaller

### 1.4 開発規律準拠
- **開発規律**: Python_1_開発規律rev003に完全準拠
- **プロジェクト構成**: 達人級・体系的必然標準構成（2.1.2節）に準拠
- **仕様書配置**: `仕様・管理/`ディレクトリに3つの仕様書を配置（プロジェクト仕様書、意思決定記録(ADR)、テスト定義書）

4. **生成実行（プレビュー必須 · rev003）**:

5. **中断**: 描画処理中に「中止」ボタンクリック → `stop_event`設定 → 安全に停止

## 3. コアロジック・計算仕様

### 3.1 データ構造

#### 3.1.1 Excelテーブル形式
- **列構成（8列版）**:
  1. ID（数値、10刻み推奨）
  2. 図形種別（端子、処理、判断、入出力、手動入力）
  3. 接続先(下)（カンマ区切り、例: "30,40"）
  4. 接続先(右)（カンマ区切り、例: "50"）
  5. Level（階層レベル、0から開始）
  6. 主処理(Text1)
  7. 詳細(Text2)
  8. 補足(Text3)

- **列構成（7列版）**:
  1. ID
  2. 図形種別
  3. 接続先(下)
  4. Level
  5. Text1
  6. Text2
  7. Text3

- **列構成（簡易版、6列以下）**:
  1. ID
  2. 図形種別
  3. Text1
  4. 接続先(下)
  5. Level

#### 3.1.2 内部ノード構造
```python
{
    "id": str,           # ノードID（文字列化）
    "type": str,         # 図形種別
    "full_text": str,    # Text1+Text2+Text3を改行結合
    "dests_down": List[str],   # 下方向接続先IDリスト
    "dests_right": List[str],  # 右方向接続先IDリスト
    "level": int,        # 階層レベル
    "ridx": int          # 元データの行インデックス
}
```

### 3.2 描画アルゴリズム

#### 3.2.1 データ解析（`_parse_data`）
1. Excelデータ（タプル）を1行ずつ走査
2. IDが数値でない行はスキップ
3. 列数に応じて8列/7列/簡易版を判定
4. 接続先文字列をカンマ区切りで分割・正規化
5. Text1-3を改行結合して`full_text`生成
6. ノード辞書と行マップを構築

#### 3.2.2 高さ計算（`_calculate_row_heights`）
1. 一時図形を生成（画面外 `-5000, -5000`）
2. 各行の全ノードについて:
   - テキストを設定
   - `AutoSize = 1`で自動サイズ調整
   - 高さを測定（`Height + 15.0`のマージン）
   - 行内の最大高さを記録
3. 一時図形を削除（清算義務）
4. 最小高さ（`h_min`）と比較して、大きい方を採用

#### 3.2.3 図形配置（`place_shapes`、`app/core/shape_placer.py`）
1. 基準位置（`base_left`, `base_top`）から開始
2. 行インデックス順に走査:
   - 前の行との間隔: `前の行の高さ + gap_v`
   - 水平位置: `base_left + (level * (width + gap_h))`
   - 図形種別判定:
     - 「判断」→ ダイヤモンド（`MSOSHAPE_DIAMOND`）
     - 「端子/開始/終了」→ 角丸矩形（`MSOSHAPE_ROUNDED_RECTANGLE`）
     - 「入出力/データ」→ 平行四辺形（`MSOSHAPE_PARALLELOGRAM`）
     - 「手動入力」→ 手動入力図形（`MSOSHAPE_MANUAL_INPUT`）
     - その他 → 矩形（`MSOSHAPE_RECTANGLE`）
   - ダイヤモンドは高さを1.3倍、垂直オフセット調整
   - 図形作成 → スタイル設定（色、テキスト） → マップに登録
3. 境界座標（`bounds`）を計算

#### 3.2.4 コネクタ接続（`connect_nodes`、`app/core/connector_manager.py`）
1. 全ノードを走査
2. 各ノードの`dests_down`と`dests_right`を処理:
   - 接続先ノードを取得
   - ループ判定: `t_node["ridx"] < n["ridx"]`
   - レベル差計算: `level_diff = t_node["level"] - n["level"]`
   - 接続点決定:
     - 下方向: 通常は`BOTTOM→TOP`、レベル差がある場合は`ELBOW`、ループ時も`ELBOW`
     - 右方向: 常に`ELBOW`、`RIGHT→TOP/LEFT`
   - 同一列かつ順方向なら直線（`STRAIGHT`）
   - コネクタ作成 → 接続 → 色・太さ・矢印設定
   - 判断図形の場合はYes/Noラベル追加
3. コネクタ名リストを返却

#### 3.2.5 判断図形の仕上げ（`finalize_composites`、`app/core/group_manager.py`）
1. ダイヤモンド図形の情報を走査
2. 各ダイヤモンドに対して:
   - 内部にテキスト枠（幅75%、高さ100%）を重ねる
   - テキストスタイル設定
   - 背景図形とテキスト図形をペア化
3. ペアリストを返却

#### 3.2.6 外枠とタイトル（`add_frame_and_title`、`app/core/group_manager.py`、フルモード時のみ）
1. タイトル位置計算: `(left + right) / 2 - 225, top - 75`
2. タイトルテキストボックス作成（幅450、高さ45）
3. 外枠作成: 全図形を囲む矩形（マージン30）
4. 名前リストを返却

#### 3.2.7 グループ化（`create_final_groups`、`app/core/group_manager.py`）
1. 判断図形のペアをグループ化（背景+テキスト）
2. 全要素（単独図形、コネクタ、タイトル、外枠、判断グループ）を最終グループ化
3. グループ名を返却

#### 3.2.8 スマート・パレットによる直接図形生成（rev013追加、`app/ui/main_window.py`の`_smart_input`メソッド変更）
1. Excel上で選択セルの位置を取得（`app.Selection`）
2. 選択セルの座標（`Left`, `Top`）を基準位置として使用
3. ボタン種別に応じた図形種別コードを決定:
   - 「端子」→ 角丸矩形（`MSOSHAPE_ROUNDED_RECTANGLE`）
   - 「処理」→ 矩形（`MSOSHAPE_RECTANGLE`）
   - 「判断」→ ダイヤモンド（`MSOSHAPE_DIAMOND`）
   - 「入出力」→ 平行四辺形（`MSOSHAPE_PARALLELOGRAM`）
   - 「手動入力」→ 手動入力図形（`MSOSHAPE_MANUAL_INPUT`）
4. 現在の設定値（`var_height`, `var_width`）を使用して図形サイズを決定
5. 図形を生成:
   - 位置: 選択セルの`Left`, `Top`
   - サイズ: `var_width`（幅）、`var_height`（高さ、判断図形の場合は1.3倍）
   - テキスト: プレースホルダーテキスト「XXXX」
   - スタイル: 現在のテーマ設定（`var_theme`）を適用
6. コネクタを生成（rev013追加）:
   - **すべての図形**: 図形の下側中央（`CONNECTOR_SITE_BOTTOM`）からカギ付き矢印コネクタ（`MSOCONNECTOR_ELBOW`）を生成
     - コネクタは図形の下側から垂直に伸び、右に90度曲がり、さらに下に90度曲がって下向きの矢印で終わる
     - コネクタの終点は接続先がないため、図形の下側から一定距離（例: 図形の高さ分）下に配置される
     - コネクタの色は現在のテーマ設定（`var_theme`）のコネクタ色を適用
     - コネクタの太さは2.25、矢印スタイルは3（`EndArrowheadStyle = 3`）
   - **判断図形のみ追加**: 図形の右側中央（`CONNECTOR_SITE_RIGHT`）からもカギ付き矢印コネクタ（`MSOCONNECTOR_ELBOW`）を生成
     - コネクタは図形の右側から水平に伸び、下に90度曲がり、さらに右に90度曲がって右向きの矢印で終わる
     - コネクタの終点は接続先がないため、図形の右側から一定距離（例: 図形の幅分）右に配置される
7. 判断図形のラベルを生成（rev013追加）:
   - **下側コネクタのラベル**: 図形の下側コネクタの始点付近に「Yes」テキストボックスを配置
     - 位置: 図形の下側中央から左にオフセット（`図形の幅/2 - ラベル幅 - 3`）、図形の下側から下に3ピクセル
     - サイズ: 幅30、高さ16
     - スタイル: 背景なし、枠線なし、フォントサイズ9、太字、中央揃え
   - **右側コネクタのラベル**: 図形の右側コネクタの始点付近に「No」テキストボックスを配置
     - 位置: 図形の右側から右に10ピクセル、図形の中央から上にオフセット（`図形の高さ/2 - ラベル高さ - 3`）
     - サイズ: 幅30、高さ16
     - スタイル: 背景なし、枠線なし、フォントサイズ9、太字、中央揃え
8. 生成された図形、コネクタ、ラベルは単独の要素としてExcel上に配置され、グループ化は行わない（ユーザーが後で手動で編集・移動可能）

## 4. 極限境界値への対処 (Edge Cases)

### 4.1 物理的遮断
- **Excel未起動**: `get_excel_app()`が`None`を返す → `RuntimeError`を発生、GUIにエラーメッセージ表示
- **選択範囲なし**: `Selection`が空 → 警告ログ、空文字列返却
- **データ形式不正**: 列数が想定外 → 簡易版フォーマットで処理を試行

### 4.2 入力の暴力
- **空のテーブル**: `data`が`None`または空タプル → 警告ログ、空文字列返却
- **ID重複**: 同じIDが複数存在 → 最初に見つかったノードのみ使用（後続は無視）
- **接続先が存在しない**: `shape_map.get(did)`が`None` → スキップ、警告ログ

### 4.3 時間の歪み
- **長時間処理**: 非同期スレッドで実行、`stop_event`で中断可能
- **Excel応答遅延**: COM操作のタイムアウトは`pywintypes.com_error`で捕捉
- **UIフリーズ防止**: `threading.Thread`で分離、`self.after()`でGUI更新

### 4.4 権限の壁
- **ディレクトリ作成失敗**: `ensure_environment()`で権限エラー検知 → エラーメッセージ表示、`sys.exit(1)`
- **ログファイル書き込み不可**: ファイルハンドラの例外を捕捉、コンソールのみで継続
- **Excel COM操作失敗**: `pywintypes.com_error`で捕捉、ガイダンス型通知を表示

### 4.5 環境の衝突
- **日本語パス**: `pathlib.Path`でUTF-8処理、フォールバックで短いパス名（8.3形式）を使用
- **高DPI環境**: `ctypes.windll.shcore.SetProcessDpiAwareness(1)`で対応（必要に応じて）
- **マルチモニター**: ウィンドウ座標のバリデーション（未実装、将来拡張可能）
