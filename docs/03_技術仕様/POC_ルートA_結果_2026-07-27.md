## 3. 起動障害と対策（rev007 初回 exe）

### 症状

- `FlowchartExcel.exe` 起動直後に落ちる
- `dist/logs/app.log` に `embedded_preview_init_failed` / `unhandled_exception_at_main`

### 原因 1（本命）— tkwebview2 × pywebview 6.x 非互換

tkwebview2 3.5.0 は `EdgeChrome.web_view.web_view` を参照するが、pywebview 5+/6+ は **`EdgeChrome.webview`** に API 変更。

```
AttributeError: 'EdgeChrome' object has no attribute 'web_view'
```

### 原因 2（増幅）— フォールバック UI の pack/grid 混在

埋め込み init 失敗後、既に `pack()` 済みの子に `grid()` しようとして TclError → 2窓フォールバックにも到達しない。

### 対策

| 対策 | 実装 |
|------|------|
| pywebview 版固定 | `requirements.txt`: `pywebview>=5.0.0,<6.0.0` |
| 互換パッチ | `_ensure_tkwebview2_compat()` — `WebView2.__init__` を差し替え、`self.web = edge.webview` |
| 起動前適用 | `main.py` で GUI 前に `_ensure_tkwebview2_compat()` |
| 堅牢フォールバック | init 失敗時は `content_frame` の子を destroy → `_use_embedded = False` → 2窓 UI |

**L1 SSOT:** `yk-skill/rule/40_python/PYTHON_RULES.md` §13「tkwebview2 + pywebview 版固定」
