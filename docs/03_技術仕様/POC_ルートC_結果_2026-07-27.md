## 3. P2 作成一致契約

1. プレビュー表示中はライブ更新（0.75s ポーリング）
2. 「Excelに作成」確定時に Excel を再読込して payload を凍結
3. 描画は凍結 payload の `table` から実行（Excel 再パースしない）
4. プレビュー窓クローズでライブ停止 → 描画と COM 競合なし

## 4. 手動受け入れ（仕様 §8 · **2窓フォールバック**向け）

本線（ルート A · 1窓）の受け入れは [POC ルート A](./POC_ルートA_結果_2026-07-27.md) の TC-037/038。  
以下は **埋め込み init 失敗時の 2窓**（`on_top` 子プロセス）用。

- [ ] Excel をクリックしてもプレビューで確認を続けられる
- [ ] 前面に選択範囲・パレット・雛形・大中小が無い（メニュー内は可）
- [ ] 「読み込み」と「Excelに作成」の役割が誤解なく使える
- [ ] 表編集 → ライブ反映 → Excel 作成が本線で完了する
- [ ] 作成内容がプレビューと一致する

### 手順（2窓フォールバック）

```text
1. Excel で 10列表を開く
2. python main.py（埋め込み不可環境、または _use_embedded=False 時）
3. 「表を読み込んでプレビュー」→ 別 WebView 窓が開く
4. Excel で表を編集 → プレビューが追従するか
5. プレビュー窓の「Excelに作成」→ 編集後の内容で図形化されるか
6. ステータスに「ライブ ON」（プレビュー中）が出るか
```

**1窓本線（rev007）:** 手順 3 で別窓が開かないこと · 手順 5 は **メインウィンドウ下部**の「Excelに作成」（TC-038）。
